isset function in PHP:

-> isset($var) returns true if the variable $var has been declared and its value is not NULL. Otherwise it returns false. 

-> If you give isset() multiple variables (e.g. isset($a, $b, $c)), it returns true only if all of them exist and are not null. 

-> It also works when you check array elements, e.g. isset($_POST["stop"]) will return true only if the array $_POST has a key "stop" and that value is not null. 

-> Note: isset() does not check whether the variable’s value is “empty” or “falsey” like 0, "", or false. Those values are considered “set” by isset(), because they are not NULL. 
Zero To Mastery

Thus, think of isset() as a presence-and-non-null check, not a content/emptiness check.

Hashing in PHP:

-> A process of transforming sensitive data such as passwords into letters, numbers and/or symbols via a mathematical process.
   It is kinda similar to encryption but it's technically different. Basically, we can hide the original data from 3rd parties such as Hackers.

-> To create a Hash, Use password_hash() function.
-> Syntax: password_hash($string, PASSWORD_DEFAULT)
   
 . The 1st parameter can be a string variable.
 . The 2nd parameter is Hashing Algorithm. It is technically a constant that specifies the algorithm. PASSWORD_DEFAULT use the bcrypt algorithm.

-> password_verify(): used to match the given hash with the plain text password. It returns either true or false based on the answer.

Retrieve Data from MySQL Database using PHP:

-> SELECT query is used to retrieve data such as:
 . SELECT * from users WHERE user = 'Zeeshan'

-> mysqli_num_rows($result): used to check the results given by query that has stored in the variable $result.
-> mysqli_fetch_assoc($result): used to access the next upcoming row of the database.
-> Use while loop with condition mysqli_fetch_assoc($result) to display all the data from the table.
-> Summary:
 . Write an SQL query.
 . Use the query function. This returns an object.
 . Get each row from the object using mysqli_fetch_assoc().
 . For more than one row, use while loop.
